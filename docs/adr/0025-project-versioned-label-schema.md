# 采用项目级可版本化标签模式

**Status: accepted**

项目不再把活动类型、地形类型和合法组合视为全局硬编码集合，而是由标注项目中的版本化标签模式定义，并以稳定内部代码和版本保存。每个模式固定有且仅有活动轨和地形轨：可配置两条轨中的标签及其组合规则，但不支持用户新增轨道。模式在首份正式标注引用前可作为草稿修改；引用后该版本永久只读，后续变化必须创建新版本并显式定义迁移，未迁移试次继续绑定旧版本，同一试次不得混用版本。已用于正式标注的标签只能停用或通过显式迁移替换，不能直接删除；内置 V2 标签模式继续作为自动识别唯一默认目标，自定义模式只接受人工标注，直到相应识别器被明确实现。这以增加配置、版本和迁移复杂度为代价，换取在不破坏历史标注或伪造自动结果的前提下支持领域演进，同时避免任意动态字段扩散到 GUI、QA 和识别器接口。
