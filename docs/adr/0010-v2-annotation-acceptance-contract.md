# V2 自动标注验收契约

V2 对 `8.3` 及冻结外部验证批次的阻断验收要求完整事件序列完全一致，包括普通组合状态边界、楼梯第二步确认和试次收尾确认，但忽略自由备注文本以及只能人工复核的具体跑步机角度；序列通过后，全部事件的边界误差还须满足 median `<=0.25 s`、P95 `<=2.5 s`、max `<=5.0 s`。冻结外部验证批次中的两名受试者必须分别通过这些门槛，同时报告批次汇总结果，不允许用一人的较好结果抵消另一人的系统性失败。逐标签 F1、宏平均 F1 和逐区间 IoU 必须报告，但本轮不设阻断阈值，因为单名 V2 开发受试者不足以为时长差异很大的标签确定可靠门槛，且事件序列与边界误差已经直接约束分段质量。
