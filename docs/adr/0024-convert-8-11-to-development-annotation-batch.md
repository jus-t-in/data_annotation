# 将 8.11 转为开发标注批次并另采外部验证数据

`8.11/P02` 和 `8.11/P03` 的完整 `T01-T05` 已依据原始传感器信号和 `8.3` 人工经验完成无同步视频条件下的人工近似标注。标注未读取、调用或比较 V2 自动标注器结果；普通边界吸附到最近真实采样点，协议只用于完整性检查，未发生的动作和暂停不补造。

从本决策起，`8.11` 明确作为开发标注批次，可用于规则设计、调参、训练、错误分析和内部回归，不再作为 ADR-0007 所述的一次性冻结外部验证集。即使其人工参考是在看不到自动结果时建立，后续开发已经允许接触和利用该批数据，因此不能再用它证明外部泛化性能。

下一次外部验证必须另采新的受试者和完整试次，并在查看其 CSV、人工参考或自动结果前冻结算法、参数和验收阈值。外部参考继续遵守 ADR-0021 的盲标、锁定和审计要求，验证报告继续遵守 ADR-0023；一旦依据该外部数据修改算法，该批同样转为开发数据，并再次另采外部批次。
