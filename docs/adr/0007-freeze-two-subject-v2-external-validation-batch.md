# 冻结两名受试者的 V2 外部验证批次

新采集的两名受试者各自完整的 `T01-T05` 均作为一次性外部留出集，在查看其 CSV 前冻结算法和验收阈值；开发只使用 8.3 的 `T01/T02/T03/T05`，8.3 的 `T04` 继续作为内部留出。外部参考标注必须由看不到自动结果的标注员依据原始信号、协议和现场条件记录独立完成并锁定，之后才运行自动算法比较。这样可以避免用仅有的跨受试者数据调参或让自动边界锚定人工参考而高估泛化能力；若后续依据这批外部数据修改算法，该批数据即转为开发数据，必须另采新受试者完成外部验证。

本决策对 `8.11` 批次的具体数据角色已由 ADR-0024 修订：`8.11/P02` 和 `8.11/P03` 已转为开发标注数据，不再属于冻结外部留出集。本文的冻结原则继续适用于未来另行采集的外部验证批次。
