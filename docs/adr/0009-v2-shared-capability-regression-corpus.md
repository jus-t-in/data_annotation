# 分层验证 V2 的共同检测能力

V2 对旧数据的硬回归以 `7.21` 中 P04/P05 的 `T01/T02` 为锁定参考，因为这两个试次的协议与共同标签在 V2 中未变；102 个事件的状态序列必须完全一致，边界误差必须满足 median `<=0.15 s`、P95 `<=2.65 s`、max `<=4.51 s`。旧 `T03/T04` 因协议或标签语义已经改变，只作非阻断诊断。

执行偏差（2026-08-04）：`7.27` 的 P06/P07 已在 ADR-0004 所述的早期算法探索中被查看，本次升级开始前也没有建立并锁定独立盲标参考，因此不能把它追认为“修改前冻结”的硬回归或外部验证集。`7.27/T01-T02` 只能用于非阻断诊断，且不得以已有 `state_changes.auto.csv` 充当人工参考。真正的跨人外部门以 ADR-0007 规定的后续两人完整 `T01-T05` 冻结批次为准。
