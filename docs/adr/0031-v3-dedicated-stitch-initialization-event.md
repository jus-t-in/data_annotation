# T04 合并记录使用专用接缝初始化事件

## 状态

已采纳（2026-08-31）。

## 决策

T04 `v3_1+2` 的唯一约 `3.000 s` 断档只表达源记录切换。第二段首个真实采样点保留一个专用“接缝初始化事件”，默认 `STILL·LEVEL`；该事件固定不可移动、不可删除，但允许修订活动、地形和备注。普通同状态边界仍按一般结构规则禁止。

V3 编辑器将现有 V2 识别器的整段输出作为“V2 建议 / V3 待复核”，不在识别器内部切分或重置；识别完成后由文档模型插入并保护接缝事件。

## 原因与后果

这样能在不新增 CSV 字段、不伪造采样、不把接缝误判为动作边界的情况下，保持两份源记录的时间语义与保存/重开可追溯性。若接缝断档缺失、数量不唯一或不是 `3.000 s ± 0.001 s`，草稿仍可打开和恢复，但正式保存必须阻断。T04/T05 的自动地形区间另列为可点击阻断 QA；既有 V2 协议 QA 只保留在报告审计信息中。

## 不采用的方案

- 不把所有同状态重复事件都放宽为合法，因为那会隐藏普通重复边界。
- 不在 V2 识别器内部按接缝切分，因为会改变既有 V2 证据与报告语义。
- 不把接缝写成新的 CSV 列或外部 splice manifest，因为七列 CSV 契约必须保持稳定。
