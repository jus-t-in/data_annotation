# V2 步态数据采集与标注说明

## 1. 目标与适用范围

V2 协议用于采集新的步态数据，并将原完整 `SQUAT` 动作拆分为下蹲、蹲姿保持和蹲起三个阶段。站立抖腿、原地转身和小幅拖步统一归为 `STANDING_ADJUSTMENT`，用于识别不应触发行走或楼梯控制状态切换的站立小动作。T05 新增真实平地与跑步机固定坡度行走，用于初步建立平地与上坡识别。

V2 是当前标签体系的更新迭代，不要求兼容旧任务。T01、T02 延续原采集内容，T03、T04 按本文更新，T05 按本文新增。协议顺序用于指导采集和检查完整性；标注必须以实际发生的动作为准，不得按预期顺序虚构边界。

## 2. 通用采集约定

- 文件名使用 `Pxx_S01_T0x_v2_<description>.csv`。`Pxx` 为受试者编号，`S01` 为采集会话，`T0x` 为 T01-T05 试次编号。
- 每个文件开头和结尾均安静直立 `3-5 s`。
- T03 各编号动作组之间安静直立 `3-5 s`；同一编号内的重复动作连续完成。
- 半蹲与深蹲是采集条件，不拆成不同活动标签。
- 楼梯及较快动作以安全为先，楼梯禁止跑动并安排保护人员。
- 场地不足以完成要求的平地步数时，记录实际步数，不得用原地踏步代替。

## 3. 采集试次

### 3.1 T01：目标地形及直接转换

文件名：`Pxx_S01_T01_v2_target_transitions.csv`

连续完成三轮往返，每轮结束后安静直立 `3-5 s`：

```text
文件开头静止 3-5 s

第 1 轮（较慢但自然）：
  平地行走至少 8 步
  -> 不停顿上楼
  -> 平台继续行走并自然转身，不静止
  -> 不停顿下楼
  -> 平地行走至少 8 步
  -> 静止 3-5 s

第 2 轮（正常速度）：重复上述路线
第 3 轮（较快但安全）：重复上述路线

文件结尾静止 3-5 s
```

地形转换处不得插入口令动作或人为停顿。

### 3.2 T02：静止重置与楼梯中途暂停

文件名：`Pxx_S01_T02_v2_reset_pause.csv`

```text
文件开头静止 3-5 s

上楼第 1 次：楼梯中途短暂停顿一次（目标短于 0.5 s）
-> 到达平台后静止 3-5 s
下楼第 1 次：楼梯中途短暂停顿一次（目标短于 0.5 s）
-> 到达平地后静止 3-5 s

上楼第 2 次：楼梯中途并脚静止一次（目标 0.8-1.2 s）
-> 到达平台后静止 3-5 s
下楼第 2 次：楼梯中途并脚静止一次（目标 0.8-1.2 s）

文件结尾静止 3-5 s
```

### 3.3 T03：分组动作

文件名：`Pxx_S01_T03_v2_actions.csv`

每名受试者完成一轮。以下各编号动作组之间安静直立 `3-5 s`：

1. 弯腰并恢复直立，连续 3 次。
2. 连续半蹲 3 次；最低位不主动停顿，顶部不主动停顿。
3. 半蹲 3 次；每次在最低位保持 `1-2 s` 后蹲起。
4. 连续深蹲 3 次；最低位不主动停顿，顶部不主动停顿。
5. 深蹲 3 次；每次在最低位保持 `1-2 s` 后蹲起。
6. 站立抖腿：左脚置于身体前方抖动 `5-8 s`，再换右脚抖动 `5-8 s`。抖动脚以前脚掌或脚跟着地，另一侧腿按口令主要承重；换脚不作为活动切换。
7. 左右交替原地高抬腿 6 次。
8. 原地向左转 2 次、向右转 2 次。
9. 小幅向前、向后、向左和向右拖步，各 `2-3` 小步。

```text
文件开头静止 3-5 s
-> 动作组 1
-> 静止 3-5 s
-> 动作组 2
-> ...
-> 动作组 9
-> 文件结尾静止 3-5 s
```

不单独采集左右单腿高抬腿，也不单独采集站姿与重心调整。

### 3.4 T04：混合留出试次

文件名：`Pxx_S01_T04_v2_mixed_holdout.csv`

```text
文件开头静止 3-5 s
-> 平地行走至少 8 步
-> 停步后立即站立抖腿 5-8 s
-> 不静止，直接再次平地行走至少 8 步
-> 静止 3-5 s
-> 无最低位停顿的半蹲 1 次
-> 最低位保持 1-2 s 的深蹲 1 次
-> 静止 3-5 s
-> 左右交替原地高抬腿 6 次
-> 静止 3-5 s
-> 平地行走
-> 不停顿上楼
-> 平台继续行走并自然转身
-> 不停顿下楼
-> 平地行走至少 8 步
-> 文件结尾静止 3-5 s
```

T04 完成正式标注，但整份 CSV 不参与训练、规则阈值选择或调整，只用于最终检验连续场景中的类别和地形切换。若根据某份 T04 调整模型或阈值，该文件不再是留出试次。

### 3.5 T05：平地与固定坡度行走

文件名：`Pxx_S01_T05_v2_incline_walking.csv`

T05 从文件开头到结尾连续录制，按“真实平地 -> 跑步机 `0°` -> `10°` -> `15°` -> `25°`”的固定顺序完成。角度均指跑带相对水平面的倾角，不是坡度百分比或设备档位。本轮不采下坡，也不以倒走模拟下坡。

```text
文件开头在真实平地静止 3-5 s
-> 按受试者自然速度完成真实平地行走
-> 跑步机 0°，3 km/h（人在跑带上经历启动和加速）
-> 跨到跑步机边缘并站立等待，调至 10° 且速度稳定在 3 km/h
-> 跨回跑带，持续行走一段时间
-> 跨到跑步机边缘并站立等待，调至 15° 且速度稳定在 3 km/h
-> 跨回跑带，持续行走一段时间
-> 跨到跑步机边缘并站立等待，调至 25° 且速度稳定在 3 km/h
-> 跨回跑带，持续行走一段时间
-> 从仍在运行的跑带下到真实平地并站立静止 3-5 s
```

每个条件只采一组，不设固定步数、步态周期数或时长；只要求持续行走一段时间，获得可辨认的连续稳定步态。真实平地允许正常行走中的自然转身。跑步机稳定行走期间不扶扶手。

跑步机 `0°` 条件下，受试者先站上静止跑带，随后随跑带启动和加速进入 `3 km/h` 行走。`0°` 行走结束后，受试者从仍在运行的跑带跨到不会移动的跑步机边缘。边缘会随跑步机一起抬升和改变角度；受试者站在边缘等待调坡，待目标坡度和 `3 km/h` 跑带速度均稳定后，再跨回跑带开始对应的正坡度行走。`10°` 和 `15°` 行走结束后重复这一过程。`25°` 行走结束后，受试者从仍在运行的跑步机下到真实平地并站立静止。条件之间不设固定休息时长，全部过程保留在同一 CSV 中。

跨入跑带后若未形成可辨认的连续稳定步态，继续当前条件或重新采集该条件，并记录实际情况。跑步机条件不得临时降低速度；正坡度有效行走只能使用坡度和速度均已稳定时获得的片段。

## 4. V2 标注类别

### 4.1 活动标签

| 代码 | 名称 | 标注范围 |
|---|---|---|
| `STILL` | 静止 | 当前动作实际停止；允许维持平衡所需的轻微晃动。蹲姿保持不属于静止。 |
| `WALKING` | 行走 | 通过交替迈步形成前进步态，包括平地、楼梯、平台和跑步机行走；跑步机上相对地面没有净位移仍属行走，行走中的自然转身也仍属行走。 |
| `BEND` | 弯腰 | 从直立前屈到恢复直立的完整动作段。 |
| `SQUAT_DESCENT` | 下蹲 | 从开始持续屈膝降低身体，到最低点换向或进入蹲姿保持。半蹲与深蹲使用同一标签。 |
| `SQUAT_HOLD` | 蹲姿保持 | 最低位停顿达到 `0.5 s` 的保持段。 |
| `SQUAT_ASCENT` | 蹲起 | 从最低点或蹲姿保持开始持续上升，到回到直立且上升停止；不含从椅子、跪姿或地面起身。 |
| `HIGH_KNEE_ALTERNATING` | 交替高抬腿 | 左右腿交替原地明显抬高的连续动作段。 |
| `STANDING_ADJUSTMENT` | 站立调整 | 站立抖腿、原地转身和小幅拖步。具体动作或左右脚变化不拆成主标签。 |
| `OTHER` | 其他动作 | 可明确辨认、但未被以上专名标签覆盖的独立动作段；T05 中扶持上下跑步机的换场动作属于此类。不能用来代替不确定波动或传感器噪声。 |

V2 不再使用 `SQUAT`、`HIGH_KNEE_SINGLE`、`TURNING_LEFT`、`TURNING_RIGHT` 和 `SHUFFLE`。

### 4.2 地形标签

| 代码 | 名称 | 标注范围 |
|---|---|---|
| `LEVEL` | 平地 | 平地及平台。 |
| `ASCENT` | 上楼 | 从楼梯进入边界到楼梯退出边界。 |
| `DESCENT` | 下楼 | 从楼梯进入边界到楼梯退出边界。 |
| `INCLINE` | 上坡 | 向前上升的连续坡面；T05 中跑步机 `10°`、`15°` 和 `25°` 共用该标签，具体角度不拆分地形标签。 |

真实平地和跑步机 `0°` 均标为 `LEVEL`。`ASCENT` 和 `DESCENT` 只允许与 `WALKING` 或 `STILL` 组合；`INCLINE` 允许与 `WALKING`、`STILL` 或 T05 换场中的 `OTHER` 组合；其他活动只允许与 `LEVEL` 组合。

`ASCENT` 专指上楼，不得用于连续上坡；`INCLINE` 也不得用于楼梯。

### 4.3 T05 条件备注

T05 不生成 `STEADY_GAIT_START` 或 `STEADY_GAIT_END`，也不以同状态确认标记表达训练范围。跑步机采集条件写入对应状态区间的边界备注，不增加 CSV 字段。

自动结果的受控条件备注只能写“条件=跑步机·平地·`3 km/h`”或“条件=跑步机·上坡·`3 km/h`；角度=待人工复核”。自动算法不得根据固定采集顺序猜测具体角度。人工复核后的正式结果将条件改为“条件=跑步机·`0°`·`3 km/h`”“条件=跑步机·`10°`·`3 km/h`”“条件=跑步机·`15°`·`3 km/h`”或“条件=跑步机·`25°`·`3 km/h`”。设备类型、角度和速度是采集条件，不是新的活动或地形标签。

“角度=待人工复核”是普通、非阻断的 QA 复核项，不是自动检测失败；该项解决前，试次不得声明为已复核。

## 5. 关键标注边界

### 5.1 蹲起三阶段

| 实际变化 | 边界后的标签 |
|---|---|
| 直立状态开始持续下降 | `SQUAT_DESCENT` |
| 最低点无停顿或停顿不足 `0.5 s`，运动方向转为上升 | `SQUAT_ASCENT` |
| 最低位停止达到 `0.5 s` | `SQUAT_HOLD`，边界回标到下降实际停止的时刻 |
| 蹲姿保持后开始持续上升 | `SQUAT_ASCENT` |
| 回到直立且上升停止 | `STILL` |
| 连续蹲起在顶部停顿不足 `0.5 s`，随即再次下降 | 直接从 `SQUAT_ASCENT` 切到下一次 `SQUAT_DESCENT` |
| 顶部停顿达到 `0.5 s` | 中间标为 `STILL` |

轻微屈膝若只是站立小动作，不形成明确、持续的身体下降，不标为下蹲；符合站立调整定义时标为 `STANDING_ADJUSTMENT`。

### 5.2 站立调整

- 站立抖腿时，标注可观察到的连续小幅往复运动，不从现有传感器推断实际承重腿或重心是否替换。
- 左右脚交换或从抖腿切换到另一种站立调整动作，不产生新的活动标签边界。
- 动作内部停顿不足 `0.5 s` 时保持同一 `STANDING_ADJUSTMENT` 段；停顿达到 `0.5 s` 时切为 `STILL`，再次动作时新建一段。
- 静止时维持平衡所需的轻微晃动仍标 `STILL`；不确定的小幅波动不得强行标为站立调整。
- 正常步幅并通过交替迈步产生位移时标 `WALKING`；明显交替抬膝但不行走时标 `HIGH_KNEE_ALTERNATING`。

### 5.3 T05 跑步机边界

- 受试者在跑步机上形成持续交替步态时标为 `WALKING`；即使相对地面没有净位移，也不标为原地动作。
- `0°` 条件中，受试者在跑带上经历启动和加速；活动边界仍按实际动作切换，起步加速不另设活动标签。
- 正坡度条件开始前，受试者站在随设备抬升的跑步机边缘等待，标为 `STILL · INCLINE`；调坡本身不切换活动标签。坡度和速度稳定后，从边缘跨到运行中跑带的动作标为 `OTHER · INCLINE`，形成持续交替步态后切为 `WALKING · INCLINE`。
- 正坡度行走结束后，从运行中跑带跨到边缘的动作标为 `OTHER · INCLINE`，站稳后切为 `STILL · INCLINE`。最终从 `25°` 跑步机下到真实平地时，地形边界以主要承重面转移的时刻为准，并吸附到最近的真实采样点。
- T05 只标注真实的活动与地形状态进入、退出边界；边界根据腿位、IMU 动态、姿态带和承重转移证据确定，不按步数或固定时长截取。

### 5.4 通用规则

- 活动和地形边界以实际动作与传感器证据为准，并吸附到最近的真实采样点。
- 同一采样时刻发生的活动和地形变化合并为一个标注事件。
- 相邻标签相同的区间合并，不按单次抖动、单个转身或单个脚步重复切段。
- 数据断档不是静止或动作证据，不能通过插值补出标注边界。

## 6. T05 数据用途与实验边界

- 本批 `LEVEL/INCLINE` 识别训练使用人工复核后的 T05 `WALKING · LEVEL` 与 `WALKING · INCLINE` 状态区间，并排除 `0°` 启动加速、跑带与边缘之间的换场动作、等待和证据不足部分；不按固定时长、步数或步态周期数截取。
- 真实平地和跑步机 `0°` 的有效状态区间作为 `LEVEL` 训练数据；跑步机 `10°`、`15°` 和 `25°` 的有效状态区间作为 `INCLINE` 训练数据。
- 跑步机 `0°` 用作真实平地与跑步机上坡之间的设备基线。真实平地采用自然速度，跑步机采用固定 `3 km/h`，因此二者差异同时包含设备和速度因素，不能解释为纯设备效应。
- 当前感知算法不使用 IMU 前后方向（z 轴向）加速度作为 `LEVEL/INCLINE` 分类特征。这是本批跑步机实验的当前设计，不表示该轴永久无效。
- 跑步机数据只用于初步建模，不代表已验证真实坡道泛化。后续必须在真实坡道上测试；效果不足时补采真实坡道数据并重新评估特征。

## 7. 旧数据用于 V2 的处理

- 旧 `SQUAT` 区间无法可靠反推下降、保持和上升边界，从 V2 训练数据中排除。
- 旧 `HIGH_KNEE_SINGLE` 区间从 V2 训练数据中排除。
- 旧 `TURNING_LEFT`、`TURNING_RIGHT` 和 `SHUFFLE` 在训练数据导出时映射为 `STANDING_ADJUSTMENT`。
- 旧 `OTHER` 只有在人工能够明确确认其属于站立调整时，才在训练数据导出时映射为 `STANDING_ADJUSTMENT`；其他 `OTHER` 保持不变。
- 其余同名标签可继续用于 V2。上述处理只发生在训练数据导出阶段，不回写或篡改旧标注文件。

## 8. 当前工具限制

当前仓库中的标注器和自动标注规则仍使用旧标签集合，协议检查也尚未覆盖本文的完整 T03-T05 行为，因此不能正式保存或自动生成本文定义的全部 V2 标签。开始 V2 正式标注前，需要先升级工具的标签集合、合法状态、显示映射、T05 状态边界与条件备注、自动标注及协议 QA；在升级完成前，不应把旧标签临时冒充 V2 标签。
