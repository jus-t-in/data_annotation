我按代码把这套工具的标注逻辑串起来了。核心是：

- **活动、地形**：用“边界”表示，从这个采样点开始生效，直到下一个同轨道边界。
- **楼梯第二步、试次收尾**：是“确认标记”，只记录某个时刻，不改变活动或地形区间。
- 同一时刻活动和地形都变化时，界面显示为一个事件，但内部仍是两个独立分量。

相关实现见 [gui.py](/home/zjh/work/data_annotation/src/youbu_annotation/gui.py:1538) 和 [model.py](/home/zjh/work/data_annotation/src/youbu_annotation/model.py:542)。

**如何定位要编辑的时刻**

- 在腿部位置、Y 轴角速度、运动/冲击、状态图上单击，光标会吸附到最近的真实采样点。
- 拖动图中的竖直光标也可以定位。
- 点击事件表中的一行，或点击标注线/标注标签，可以选中事件。
- 如果一个事件同时包含活动边界和地形边界，需要在“事件分量”下拉框中选择具体要改哪一个。

桌面辅助图中的“Y 轴角速度”用于观察转向过程，读取 `Gyroscope/Gyro Y`，保留原始单位和正负号，并显示零参考线。主曲线采用 25 个采样点的居中均值平滑（不足 25 点时使用全部采样点）；勾选“原始通道”可叠加未经平滑的曲线，核对转向起止。正负方向沿用传感器坐标定义，不直接标为左转或右转。

**新增标注**

| 操作 | 实际效果 |
|---|---|
| 添加活动边界 | 在当前光标采样点添加一个活动状态，立即生效 |
| 添加地形边界 | 在当前光标采样点添加一个地形状态，立即生效 |
| 添加确认 | 在当前光标采样点添加“楼梯第二步确认”或“试次收尾确认” |

新增的边界和确认来源都是“人工新建”。

地形边界从当前真实采样点起生效，一直持续到下一条地形边界；离开楼梯或坡面时，再添加“平地”或下一种地形边界。人工补充地形边界不会自动改变活动轨。
V3 的地形下拉包含“平地、上楼、下楼、上坡、下坡”五个选项。

注意：

- 同一轨道、同一采样点不能重复添加边界。
- 确认标记添加时只检查是否在试次范围内，是否合法通常要等结构校验时才显示。

**修改标注**

1. **修改标签**

   选中活动或地形边界，在“标签”下拉框中修改。

   修改后，该标签会从这个边界开始影响后续区间，直到同一轨道的下一个边界。修改自动标注的标签后，来源会变成“自动生成后人工调整”。

2. **修改时间**

   有两种行为：

   - 在右侧“相对时刻”输入时间，或点击前后采样点按钮：移动整个事件。
   - 直接拖动状态轨上的某一条边界线：只移动这一条活动或地形边界。
   - 拖动确认线：只移动确认标记。

   边界不能移动到相邻边界之外，也不能移动起始状态。时间最终都会吸附到真实采样点。

   如果活动和地形在同一事件中同时变化，修改右侧事件时间会同时移动这两个分量；直接拖线则只移动其中一条。

3. **修改备注**

   选中分量后修改“判断依据”。备注必须是单行、最多 500 个字符。修改备注不会改变来源类型。

4. **修改确认类型**

   界面没有直接修改确认类型的入口。要把“楼梯第二步确认”改成“试次收尾确认”，通常需要删除原确认，再重新添加正确类型。

**删除标注**

先选中具体分量，然后使用：

- “删除分量”按钮
- 编辑菜单中的删除
- `Delete` 键

工具会要求输入删除理由。

规则如下：

- 起始状态不能删除。
- 删除自动生成的边界或确认，必须填写理由，并会写入报告的删除记录。
- 删除人工新增或来源不明的分量时，理由可以为空。
- 删除一个状态边界后，前一个状态会继续延伸到下一个边界。
- 删除确认标记不会改变活动或地形区间。
- 如果事件同时包含活动和地形，删除时只删除当前选中的那个分量。

**自动清理行为**

模型会自动整理相邻的重复标签。例如同一轨道出现：

```text
STILL -> WALKING -> WALKING
```

后一个多余的 `WALKING` 边界会被规范化删除。

因此，把某个边界改成与前一个边界相同的标签，可能导致这个边界消失；把它改成与后一个边界相同的标签，可能导致后一个边界被合并掉。这是为了保证每个边界确实代表一次状态变化。

**确认标记的有效条件**

保存前会校验：

- 楼梯第二步确认必须位于“行走 + 上楼/下楼”区间内。
- 同一个楼梯区间最多一个第二步确认。
- 试次收尾确认必须位于“静止 + 平地”区间内。
- 一个试次最多一个收尾确认。
- 确认标记不能与状态边界或其他确认处于同一采样点。
- 每条轨道必须有采样点 0 的起始状态。
- 不允许同轨道相邻边界使用相同标签。
- 活动和地形组合必须是有效组合。

**撤销、复核和保存**

- 每次新增、删除、移动、改标签都会进入撤销历史。
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做。
- 重新自动识别会把整份当前草稿替换掉，但整体作为一次操作进入撤销历史。
- 除了单纯修改备注，其他结构或标签修改通常会清除“已复核”状态，需要重新复核。
- 正式保存必须同时满足：结构无错误、QA 问题全部闭环、填写标注员并完成时间线复核。
- 保存时只替换当前 `input_file` 对应的 CSV 行，其他试次的行会保留。

推荐的实际操作顺序是：先用光标定位，再添加或移动边界；然后检查状态区间和确认标记；处理 QA；最后完成复核并正式保存。
