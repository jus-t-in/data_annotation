# 领域文档

本仓库采用单上下文领域文档布局。

## 探索前必读

- 阅读仓库根目录的 `CONTEXT.md`。
- 阅读 `docs/adr/` 中与待修改区域相关的 ADR。
- 如果任一路径不存在，直接继续，无需报告。

## 布局

```text
/
|-- CONTEXT.md
|-- docs/adr/
`-- src/
```

## 词汇

在 issue、提案、假设和测试名称中使用 `CONTEXT.md` 定义的术语，避免使用词汇表明确排除的同义词。

如果所需概念尚未定义，应先重新判断它是否属于本项目；若确属缺口，则记录下来交由 `domain-modeling` skill 处理。

## ADR 冲突

如果产出与现有 ADR 冲突，应明确报告，而不是静默覆盖既有决策。
